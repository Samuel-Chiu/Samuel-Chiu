The other is the version I submitted as part of my project where I accessed and ran the file on a linux server.

Now lets talk about what this program does. This program takes Hawaiian rainfall data of the Hawai'i Climate Data Portal from 1990 - 2012.
It computes where in Hawai'i the largest difference in rainfall was comparing the legacy rainfall model and the new rainfall model. 
It prints out when the largest difference in rainfall was, then shows you with a line plot, how the differences change over time between the two models. 

Then for that year (and specified month), it visually shows you 4 plots of rainfall for that month in Hawai'i. 
The first model coming from the legacy database, the second model coming from the New Database, 
the third model showing the difference between the two, and the fourth showing the average of the difference across the entire year.
